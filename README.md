# Flask Sentiment Analysis API

A Flask web API that allows users to manage tweets and perform sentiment analysis.  
The API uses Hugging Face's `transformers` library for sentiment classification.

## Features

- Retrieve all tweets or filter by date.
- Add new tweets via POST requests.
- Perform sentiment analysis on tweet content.
- Fully JSON-based API responses.
